# Multiparty biological process examples

`reactome-egfr/bundle.json` pins nineteen original Reactome query JSON responses,
138,226 bytes, with individual SHA-256/version/source/CC0 attribution. The offline
reader projects three reactions and fifteen molecular states, retaining precise
multiplicities, compartments, molecular identities, modifications, complexes and
alternative sets. This is an unreviewed declaration, not a kinetic model.

Read [E7](../../docs/epics/E7-multiparty-processes.md) for operator/API/UI usage,
ownership exclusions, instance-frame semantics and explicit scientific limitations.
Original data remain pristine; linked figures/media are not downloaded.
