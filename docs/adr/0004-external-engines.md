# ADR 0004: Reuse specialist engines behind explicit scientific ports

Status: accepted. Date: 2026-10-15.

Do not build one engine intended to replace molecular, cell, tissue, neural and
physiological solvers. Register engine-specific models and mediate scientifically
defined couplings. Ports declare units, semantic identity, scale, geometry and
ownership. Feedback needs a numerical coupling solver, not only a topological sort.

Consequence: real integration is slower than connecting arbitrary matching JSON
fields, but preserves scientific meaning and numerical accountability.
