# Validation

Aligned scalar evaluation, heldout-role/group checks, frozen dataset splits and
run-bound retrievable records. Splits are declared, not independently certified.
General uncertainty/sensitivity and independent governance remain future gates.
The limited `cornea_front_identifiability` module now inverts two early projected
areas into assumed lag/rate compatibility and future envelopes. Its optimistic
minimax precision test can withhold an unsupported claim. These are nonstatistical
model-family bounds, not biological coverage or a clinical confidence interval.

`cornea_evidence` supplies offline inert original-workbook/JATS observations and
actual lattice geometry. The optional corneal repair operators compare exact
completed child artifacts with all admitted observations and frozen criteria;
they retain cohort/individual disagreement and a failed independent challenge.
See experiments/vcornea/repair-front at repository root. These are explicit
offline experiments, with no default engine registration or global validity promotion.

`cornea_forecast_evidence` separately parses the original Suárez-Barrio2019 Table1
without executing formulas or resolving XML resources. It preserves all28 printed
means/SDs, source coordinates and unknown eye/animal counts, and isolates Control
0/24h conditioning from all later values. Forecast time starts at the24h anchor;
normalization uses the original injury baseline. Exact observed failures and the
prefix-only audit are retained in the conditioned-forecast experiment.

`cornea_online_evidence` separately adapts all16 original series from the three
consumed2017/2019/2021 sources. Actual rabbit ratios, cohort-mean ratios and
published group aggregates remain distinct, with original units/cells/SD/context.
The2021 arithmetic0h normalization is not a conditioning measurement; categorical
closure is never a numeric zero. The explicit online-forecast operator conditions
each isolated child on only its available prefix and retains all98 next targets
(96 numeric,2 categorical), per-series comparisons and failure. Regression tests
replay checked actual outputs without launching scientific jobs. This does not
certify split independence or authorize default API model execution.

Frozen repeated-seed protocols provide paired scalar regression against imported
simulation references. They require matching seed sets and time grids, preserve
per-seed errors and fail unless every sample passes the fixed tolerance. They do
not estimate uncertainty or prove stochastic-distribution equivalence. See
docs/compucell-output.md.
