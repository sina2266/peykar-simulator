# Synthetic scalar import fixture

These are locally invented tab-delimited tables for import and paired-seed
regression tests. They are not CompuCell3D or vCornea outputs and provide no
biological evidence. Column names and a half-second time mapping are arbitrary,
explicit fixture choices. No engine or model code was executed.

The source/runtime SHA-256 declarations hash `source-descriptor.txt` and
`runtime-descriptor.txt`, which state those limits. The engine version in each
mapping is example metadata, not a runtime installation claim. Original fixture
material uses the repository's existing license; no upstream license is inferred.

See docs/compucell-output.md for the complete CLI workflow and limitations.
